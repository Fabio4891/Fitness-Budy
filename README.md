# Fitness Budy

Persönliche Fitness-Web-App (PWA): Trainingsplan mit Progression, Satz-Log mit Pausen-Timer, Kalorien und Ernährungsplan, Wasser und Supplements, Körpermasse mit Fotos, Wochenübersicht und Diagramme.

- Alle Daten bleiben lokal im Browser (localStorage, Fotos in IndexedDB). Backup über Einstellungen.
- App-Code: `src/app.html`. Nach Änderungen `./build.sh` ausführen, das erzeugt `index.html`.
- Gehostet über GitHub Pages (Branch `main`, Ordner `/`).
